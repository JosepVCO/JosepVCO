### Tools I'm building, based on problems I met at work

Public APIs and synthetic data only, nothing from any employer.

**hubspot-postgres-sync** *(planned)*
Incremental HubSpot to PostgreSQL sync with pagination, rate limit handling
and a Reverse ETL mode.

**meta-ads-extractor** *(planned)*
Pulls Facebook and Instagram Ads metrics through the Meta Graph API, with
token expiry handling and error triage.

**webhook-validator** *(planned)*
Verifies signatures, validates payloads against a JSON Schema and replays
failed events.
